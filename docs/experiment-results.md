## 核心性能

下列为 HyperCD* 的记录总时间（初始化 + 算法执行）的三次均值，以及 baseline 总时间 / HyperCD* 总时间。两套作者时钟口径不同，不能将这些比值与进程端到端时间加速混同。

- **HI**：HyperCD* 0.119904 s；baseline 0.838184 s；加速 6.99×。
- **CO**：HyperCD* 0.654531 s；baseline 3.041748 s；加速 4.65×。
- **GE**：HyperCD* 0.940615 s；baseline 6.966831 s；加速 7.41×。
- **DB**：HyperCD* 2.418217 s；baseline 19.946127 s；加速 8.25×。
- **DF**：HyperCD* 2.572900 s；baseline 20.319503 s；加速 7.90×。
- **THS**：HyperCD* 14.583263 s；baseline 135.366679 s；加速 9.28×。
- **AM**：HyperCD* 20.746230 s；baseline 122.856120 s；加速 5.92×。
- **TAS**：HyperCD* 18.738793 s；baseline 98.711451 s；加速 5.27×。
- **AMZ**：HyperCD* 502.635667 s；baseline 2488.760445 s；加速 4.95×。

在可完整比较的 9 个真实数据集上，加速比为 4.65–9.28×。这支持当前硬件与公开输入下 HyperCD* 的性能优势；SOA 上 baseline 没有成功结果，因此不能把它表示为无限加速或补画成功柱形。

## 过滤、规模与线程扩展

过滤消融及逐轮计数保留 LB、RUC、SUC 与组合策略的结果，逐组数值见 `filter_ablation` 和 `iteration_computations`。10 个真实数据集的 RUC 时间占执行时间比例约为 **8.71%–22.99%**；该比例衡量过滤本身的开销，不能直接当作算法节省的总时间。POW-L 的过滤统计三次超时，比例缺失。

AMZ、TAS、SOA、AM 的 5 档规模实验全部完成，每组 3 次。曲线应结合各子集实际超边/节点统计解释；公开抽样器生成的实际输入不能只以百分比标签代替。

AMZ、SOA 的 64 线程相对本批次 1 线程加速分别为 **33.51×、47.69×**。POW-L 的 64 线程均值为 **875.79 s**，但 1 线程的三次尝试均超时，因此不提供其相对 1 线程的精确加速比。线程扩展采用独立的并行实现，不与核心单线程批次混作同一个配置。

## POW-S / POW-L 与论文比较

输入采用作者公开生成器，固定种子 5012，具体参数及统计见 [数据说明](../data/README.md)。HyperCD* 在 POW-S 上的记录总时间均值为 **1,343.21 s**，在 POW-L 上为 **18,692.80 s**；论文表 5 的对应总时间为 720 s、19,800 s。该比较保存在 [table-5-comparison.json](../data/results/full-paper/table-5-comparison.json)，不能仅凭总耗时接近就推断输入完全相同。

原论文机器、公开数据版本、生成输入的结构、预处理计数与计时边界均可能影响绝对值。本机采用双路 EPYC 7543，论文采用双路 Xeon Gold 6342；内存容量及本项目虚拟地址空间限制也不同。实际数据 manifest 和论文表 4 分开保留，不将作者数组长度与真实节点/超边数量混为一谈。

图读数、论文正文与图表间的冲突按原始比较 JSON 保留，不强行修改实验数字使其贴合原图。上述因素是解释差异时需要考虑的条件，不是已经被单独控制实验确认的因果结论。

## 审计与可重建性

最终审计状态为 `passed_with_recorded_experimental_failures`，审计问题清单为空；核查了 28 份输入、3 个实验二进制、运行器源文件、204 条完整 core 输出记录及 23 条失败记录。

完整输出校验依据运行时全量 SHA 与参考的比较。最终审计检查完整 CSV 的存在与大小，没有第二次重新读取全部 CSV 计算 SHA，因此不能把本次审计描述为又做了一遍全量输出内容验证。

本地小型归档共有 470 个清单文件，每个文件均带大小与 SHA256；本项目 49 个代码文件有单独指纹。大型原始输入、处理后输入、完整 core CSV 留在服务器，不随 Git 仓库下载。当前代码通过 18 项测试；从冻结 `input/` 重新生成的汇总除生成时间外与归档一致。

最终 IEEE 报告位于本地 `reports/ieee-reproduction/DSAA5012-IEEE-Reproduction-Report.pdf`，源文件和图表保留在同目录。报告与大数据不作为新的代码提交内容。
